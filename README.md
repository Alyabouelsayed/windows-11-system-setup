# 🛠️ Windows 11 Endpoint Baseline Setup & Desktop Administration

## 📌 Overview
This project documents the installation, baseline security setup, user administration, and system maintenance of a **Windows 11 Professional** endpoint environment. It illustrates practical desktop support practices required for deploying enterprise workstations, managing user profiles, applying security patches, and troubleshooting hardware devices.

---

## 🎯 Lab Objectives
* **OS Environment Configuration:** Complete Out-Of-Box Experience (OOBE) and establish clean desktop baselines.
* **User & Access Management:** Create local user profiles, configure privileges, and manage account security settings.
* **System Maintenance & Updates:** Deploy Windows Updates and ensure system patch compliance.
* **Device & Driver Diagnostics:** Verify hardware component functionality and troubleshoot device driver conflicts.

---

## 🛠️ Tools & Technologies
* **Operating System:** Windows 11 Professional
* **Administrative Tools:** Administrative Tools (`sysdm.cpl`), Device Manager (`devmgmt.msc`), Computer Management (`compmgmt.msc`), Local User Management.
* **Core Competencies:** IT Helpdesk Support, Desktop Troubleshooting, User Profile Administration, Patch Management.

---

## 📑 Detailed Implementation Steps

### Phase 1: Environment Setup & Account Management
1. Completed initial OS setup and system localization settings.
2. Created standard user profiles and administrative accounts following the Principle of Least Privilege (PoLP).
3. Configured user account control (UAC) prompts to enhance desktop access security.

### Phase 2: System Personalization & Performance Optimization
1. Configured Windows system preferences, privacy settings, and default application behaviors.
2. Optimized boot startup programs to reduce background resource utilization.
3. Configured display, network adapter properties, and power management options.

### Phase 3: Patch Management & Driver Diagnostics
1. Executed **Windows Update** to install critical security updates and baseline patches.
2. Utilized **Device Manager** to inspect all installed system components (Network adapters, Audio, Display adapters).
3. Performed hardware verification and driver updates to ensure overall system stability and performance.
